About Recipe Portal

Recipe Portal is a place to discover, share, and organize recipes — built as a learning project to explore how a full web application comes together with Flask.

🔍

Browse Freely

Anyone can browse all recipes and read full details — no account required.

✍️

Share Your Own

Create a free account to add your own recipes, complete with categories, prep time, and servings.

🥗

Nutrition Info

Every recipe shows an estimated nutritional breakdown, powered by the Spoonacular API.

Built With

  • Flask, Jinja2 templates, Flask-WTF (CSRF-protected forms)
  • Flask-Login for authentication and session management
  • Flask-SQLAlchemy for the database layer
  • Bootstrap 5 for responsive UI
  • Spoonacular API for nutrition estimates
